# AI Radar

| Field | Value |
|-------|-------|
| Slug | `ai-radar` |
| Version | 1.0.0 |
| Category | SEO |

Scans how visible your site is to AI crawlers and assistants — robots.txt access, llms.txt discoverability, and schema.org markup — and applies the fixes it finds once you approve them. Read-only scans run on their own; changes such as editing robots.txt or generating llms.txt ask first.
