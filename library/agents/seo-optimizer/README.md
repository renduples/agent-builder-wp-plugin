# SEO Optimizer

| Field | Value |
|-------|-------|
| Slug | `seo-optimizer` |
| Version | 1.0.1 |
| Category | SEO |

Audits posts and pages for on-page SEO, finds content that needs attention, and proposes concrete improvements to titles, metadata, and internal links. Audits and analysis run on their own; applying changes to a post asks for your approval.
