# Skills Assistant

| Field | Value |
|-------|-------|
| Slug | `skills-assistant` |
| Version | 1.0.1 |
| Category | Developer |

Bundled Agent Builder agent. Powers the Basic-mode view of the Skills page — drafts, edits, and manages skills (the reusable how-to instructions agents load on demand) on a user's behalf, and finds/imports skills other people have already published. See `agent.json` and `abilities.json` for tools and capabilities.
