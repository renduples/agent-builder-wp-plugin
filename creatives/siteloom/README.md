# Siteloom AI Agents artwork

Sources for the WordPress.org listing art in `.wordpress-org/` (icons and banners). Not shipped in the plugin zip.

- `icon.svg`: listing icon (gradient square, white loom mark)
- `mark.svg`: mark on its own (gradient, transparent background) for use on light backgrounds
- `banner-*.svg`: banner sources; all text is converted to outlines
- `make.py`: regenerates the SVGs (needs Python fontTools and Noto Sans Bold/Regular)

Mark: three vertical warp threads (the site) with one S-shaped weft thread (the agents) weaving over and under them; the two nodes are agents.
Colours: #5b56db to #ab4ff3 (the existing brand gradient). Text #1f2328, tagline #5a6370.
Font: Noto Sans (SIL Open Font Licence 1.1), outlined; the font files are not included here.
PNG renders: headless Chrome, exact listing sizes (icons 128 and 256, banners 772x250 and 1544x500).
