# AgentStructor artwork

- Icon: the original Agent Builder "A" mark (`assets/icon.svg`, copied to
  `.wordpress-org/icon.svg` and rasterised to `icon-128x128.png` /
  `icon-256x256.png`).
- Banners (`.wordpress-org/banner-1544x500.png`, `banner-772x250.png`): the
